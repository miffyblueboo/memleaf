## Implemented since the previous checkpoint

- Physical provenance and stable original spans are distinct from model semantic
  roles. Whole-turn example suppression, n-gram authorization and the short-user-
  text bypass are removed. Valid quoted documents can be explicitly bound.
- Gate coverage and exact evidence quotations are cross-validated; one generic
  bounded missing-evidence correction returns through the same candidate checks.
- Automatic summary context/source keys are restricted to admitted spans.
- Candidate/evidence/operation accounting is separated. Known missing/truncated
  observations cannot be cleared by a model NO_CHANGE; hosts surface incompleteness.
- Hermes/Codex retain bounded complete structured records, source metadata and
  explicit overflow counts. Retention loss and contradictory repeated results
  are conservative diagnostics, never evidence of new facts.
- Full frozen write requests, optimistic revision checks and forward recovery
  now cover CREATE/UPDATE/remember and explicit Scope retirement. Interrupted
  final accounting is resumed without a fresh model summary.
- Exact deduplication checks candidate/pending/commit-time active results and
  keeps independently titled tasks distinct. Unresolvable competing target
  writes do not overwrite newer shared state.
- Existing-source read-only audit and isolated process --dry-run are available.
  Details, budgets and limitations are in `docs/general-processing.md`.

### Regression classification and fixture changes

- Real code defects: whole-turn example scope; false lexical/short-text support;
  missing coverage; evidence/candidate count conflation; dropped tool metadata;
  rework citing the completed clause; correction target rejected before its
  explicit authorization; non-frozen retry; stale/shared target revisions;
  summary source leakage; equal-body independent-task deduplication.
- Deterministic model fixtures: downstream tests already prescribe model semantic
  answers. They now also provide exact evidence quotes/coverage using a test-only
  adapter. These do not count as live model decisions or new semantic proof.
- Invalid placeholder inputs: independent facts now appear in actual user/tool
  input; assistant-only summaries cite admitted keys. Original memory IDs,
  update/history/source and rejection assertions remain.
- Failure injection now targets the final semantic watermark/commit, not the
  ordinal second atomic JSON write, because plans add preceding journal writes.
- Scope migration retries now expect no second model generation after a frozen
  plan exists. Evidence-only deferrals use unresolved_evidence_count rather than
  falsely incrementing deferred_candidates.
- No existing failing test was deleted, skipped merely to pass, or changed from
  an expected write to zero writes. The original Windows fail-fast checks remain.

This does not promise semantic perfection: exact source validation proves where
text came from, not entailment or future value. Existing syntax recognizers are
hints or narrow defensive checks. Unsupported/large ambiguous observations
remain partial rather than guessed; read-only audit does not semantically
repair legacy memories. No unsafe automatic old-Vault cleanup or PyPI yank is
part of this change.
