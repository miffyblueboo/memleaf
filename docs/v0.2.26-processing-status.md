# 0.2.26 processing status

The incomplete 633-test draft and partial transfer checkpoints are superseded.
The controlled four-increment refactor is documented in [core-refactor.md](core-refactor.md)
and [evidence-retention.md](evidence-retention.md). Consult the exact PR/main commit
and its CI for verification; metadata saying 0.2.26 alone does not prove publication.

The maintained boundaries are Markdown storage and stable IDs, one shared Vault,
Hermes official MemoryProvider, native-memory coexistence, stdio MCP, independent
Model Route, and Scope Map -> search -> selected read with global todo pagination.
No database, vector service, daemon or runtime dependency was introduced.

Model semantics remain model-owned. The refactor removes post-Gate business
rewrites rather than promising perfect natural-language understanding. Local
contract tests use explicit model fixtures; the maintainer will perform live-model
acceptance locally. That decision is not reported as a passing live-model test.

Known limits: recording controls have a documented explicit vocabulary; externally
edited Markdown follows filesystem state; forward recovery is not an all-Vault
atomic transaction; intentionally excluded/truncated evidence cannot be recreated;
old abandoned host caches are not destructively purged by upgrade. Conservative
validation may defer uncertain inputs and does not prove semantic truth.
